This repository contains the R code required to perform GWAS on emergence and late blight resistance in tetraploid potato based on SNP array genotypes for a breeding population. The results are published in:

Aalborg, T., Christiansen, M. T., Romé, H., Chawade, A., Bagge, M., and Nielsen, K. L. (2026). Drone-imaging assisted genome-wide association studies reveal key quantitative trait loci for emergence and late blight resistance in tetraploid potato. Crop Sci 66, e70261. doi: 10.1002/csc2.70261

Currently uploaded are the scripts required to perform population stratification analysis based on genomic relationship matrix, conduct GWAS using the GWASpoly package, compute variance components, and annotate QTLs. 

The files also include scripts for preliminary genotype and phenotype analysis. 

The genotype and phenotype data the analysis is based on is publicly available at the Zenodo repository: https://doi.org/10.5281/zenodo.17251323. Note that due to confidentiality agreements on the custom SNP array the genomic positions of the array markers are masked in the genotype dataset.
